# DAP System Solutions

## Hackathon UniCesumar 2026

Projeto desenvolvido durante o Hackathon UniCesumar 2026 pela equipe
DAP System Solutions.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como uma experiência acadêmica de
colaboração, inovação e aplicação prática de tecnologia para análise
de um problema de relevância social.

A proposta demonstra como ferramentas de análise e visualização de
dados podem transformar informações complexas em representações mais
claras e compreensíveis.

## 🔎 Fonte e referência

**Fonte dos dados:** Portal da Transparência do Estado do Rio Grande do Sul.

**Base utilizada:** Despesas das Enchentes de 2024 – Pagamentos.

🔗 [Acessar a fonte oficial dos dados](https://www.transparencia.rs.gov.br/calamidade-publica-2024/1-principal-despesas-enchentes-de-2024-pagamentos/dados/)

Os dados apresentados neste projeto são provenientes de fonte pública
oficial e foram utilizados para fins acadêmicos no contexto do
Hackathon UniCesumar 2026.


## 🎯 Tema do projeto

### Transparência e Equidade na Reconstrução do Rio Grande do Sul

O projeto aborda a reconstrução do Rio Grande do Sul após as enchentes
de 2024, utilizando dados públicos para facilitar a visualização e
compreensão das informações relacionadas aos recursos destinados às
ações de reconstrução.

## 💡 Objetivo

Transformar dados públicos em informações visuais e acessíveis,
facilitando a análise dos recursos relacionados à reconstrução do
Rio Grande do Sul.

## 📊 Tecnologia utilizada

- Qlik
- Análise de dados
- Visualização de dados
- Dashboard interativo

## 📈 Solução desenvolvida

A equipe desenvolveu um dashboard utilizando a plataforma Qlik,
permitindo visualizar e analisar os dados relacionados aos pagamentos
e recursos destinados à reconstrução.

## 🗂️ Dados

Os dados utilizados no projeto têm como referência informações
públicas relacionadas às despesas e pagamentos das enchentes de 2024.
